# Code of Conduct

This project follows the [Contributor Covenant, version 2.1][covenant].

We expect contributors and maintainers to treat each other with respect and
to engage constructively. Harassment, discrimination, and personal attacks
will not be tolerated in issues, pull requests, discussions, or any other
project space.

## Reporting

Concerns about behaviour in the project (issues, pull requests, discussions)
can be reported to the maintainers by:

- Opening a [GitHub issue](https://github.com/jrollin/cartog/issues) and
  marking it as a conduct concern (note: issues in a public repository are
  visible to everyone — use the private channel below for sensitive reports).
- For anything you'd rather keep confidential, email the repository owner
  directly (see the commit log for current maintainer addresses).

All reports will be reviewed promptly and handled in confidence. Maintainers
will follow the [Enforcement Guidelines][enforcement] from the Covenant when
deciding what action to take.

[covenant]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
[enforcement]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines
